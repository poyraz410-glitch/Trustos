Üyelik durumu
Önce Firebase'e bağlan.
İlk kurulum için yönetici adımı
Güvenlik kuralları herkese açık üyelik oluşturulmasına izin vermez. Firebase Console → Firestore Database → Data bölümünde, bu çalışma alanı için workspaces / ÇALIŞMA_ALANI / members / UID yolunda bir belgeyi yönetici olarak oluştur. Belge alanı olarak role = owner ekle. Aşağıdaki çalışma alanı ve UID değerlerini aynen kullan. Bunu yalnızca güvendiğin kullanıcılar için yap.
Çakışma politikası: Bu prototip bulut verisini otomatik olarak birleştirmez. Buluttan içe aktarma mevcut yerel zincirin yerine geçebilir; önce JSON yedeği al. Birden fazla cihazın aynı anda yazması için sunucu tarafı kurallar ve daha gelişmiş bir eşitleme modeli gerekir.

Yedekle

Yerel zinciri JSON olarak indir.

Geri yükle

Yalnızca hash ve bağlantı kontrolünden geçen JSON zincirleri kabul edilir.

Kurulum adımları

1. Firebase Console'da proje oluştur.
2. Project settings → Your apps → Web app ekle.
3. Authentication → Sign-in method bölümünde Anonymous oturum açmayı etkinleştir.
4. Firestore Database oluştur.
5. Aşağıdaki kuralları Firestore Rules bölümüne ekle.
6. Web config alanlarını Bulut bağlantısı sekmesine gir.
7. Önce demo verisiyle test et.

Firebase ücretleri ve limitleri projene göre değişebilir. Canlıya almadan önce faturalandırma ve kota ayarlarını kontrol et.

Örnek Firestore güvenlik kuralları

Bu kurallar yalnızca giriş yapmış kullanıcıların kendi UID alanlarına yazmasına izin veren başlangıç şablonudur. Uygulama tarafındaki doğrulama, güvenlik kuralının yerine geçmez.

Not: Yukarıdaki kurallar, üyelik belgeleri güvenilir yönetim süreciyle oluşturulmadıkça yazmayı engeller. Bu HTML prototipi üyelik yönetimi sağlamaz; önce Firebase Console'da kendi UID'n için members belgesi oluşturman veya sunucu tarafında güvenli davet akışı geliştirmen gerekir. Kuralları gevşeterek herkese açık yazma açma.

Şeffaf kapsam

Var: Yerel kayıt defteri, SHA-256 hash zinciri, JSON/CSV yedek, Firebase bağlantı iskeleti, anonim oturum açma denemesi, çalışma alanı bazında yükleme/indirme.

Henüz yok: Gerçek merkeziyetsiz ağ, düğümler arası konsensüs, dijital imza ile kayıt sahibi kanıtı, otomatik çatışma çözümü, denetlenmiş üretim güvenliği.

Önemli: Tarayıcıdaki hash zinciri, kullanıcı cihazının tüm verileri yeniden yazmasını engellemez. Üretim sisteminde sunucu tarafı doğrulama, erişim denetimi ve bağımsız güvenlik incelemesi gerekir.
